## 1. 项目定位

Hydrocarbon_Generator 是一个 **有机分子同分异构体枚举 + 可视化 + 导出** 的桌面软件（Python）。给定分子式，自动生成所有不重复的结构异构体，并支持 3D 结构、键线式（skeletal formula）展示，以及导出量子化学计算用的 Gaussian 输入文件（.gjf）。

核心引擎以 `networkx.Graph` 为统一数据表示（节点=原子，边=化学键，携带 `label` / `bond_type` / `halogen_counts` / `oxo_counts` 等化学属性）。

## 2. 核心功能

### 2.1 异构体自动生成

按分子式的不饱和度 `k = 环数 + 双键数 + 2×三键数` 自动分类并枚举：

| 通式 | 覆盖类型 |
|---|---|
| CₙH₂ₙ₊₂ | 烷烃 |
| CₙH₂ₙ | 单烯烃 / 单环烷烃 |
| CₙH₂ₙ₋₂ | 单炔烃 / 二烯烃 / 单环烯烃 / 双环烷烃 |
| CₙH₂ₙ₋₄ | 烯炔烃 / 三烯烃 / 单环二烯烃 / 三环烷烃 |
| CₙH₂ₙ₋₆ | 四烯烃 / 单环三烯烃 / 四环烷烃 |
| CₙH₂ₙ₋₂ₖ | k-烯烃 / 单环多烯烃 / k-环烷烃 / 多环多烯炔烃 |

支持含 **C、H、O、卤素(F/Cl/Br/I)、氘代 D** 的分子式输入。
**含氮（N）** 由独立模块 `Nitrogen/` 处理（见 2.4），暂未并入主程序输入解析。

### 2.2 卤代烃

F / Cl / Br / I 的单取代与混合取代。在碳骨架异构体基础上用多维回溯枚举卤素取代位置，WL 哈希 + 同构去重。

### 2.3 含氧衍生物

覆盖醇 / 酚 / 醚 / 醛 / 酮 / 羧酸 / 酯 / 过氧 / 环氧 / 含 O 杂环。采用「骨架不饱和度 k 下探 + 骨架 O 桥（醚桥 / 过氧桥 / 双醚桥）+ 环氧 + O 在环 + 数学口径过滤」策略，与 MAYGEN 的数学完备口径一致（如 C7H6O2 覆盖率约 98.7%）。

### 2.4 含氮化合物（独立模块，尚未接入 GUI）

纯 **C/H/N** 有机物（胺 / 腈 / 亚胺 / 偶氮 / 含 N 杂环）的**完备枚举**，位于 `Nitrogen/`。

- **化学口径**：中性八隅律 **C = 4 / N = 3**（与 MAYGEN 默认价态表一致）；
  氮规则 DBE：`k = nC − nH/2 + nN/2 + 1`。
- **双引擎**：完备性预言机 `atomic_matrix_n.py`（邻接矩阵原子级枚举）
  + 树机制生成器 `generator.py`（C→N 替换 / 端基 N / 桥 N 三种机制）。
- **验证入口**：`validate.py` 六项内部检查（门禁冒烟 / 内部基线 / 化学事实锚点 /
  预言机自洽 / 双向差集覆盖率 / 全 H 档位守卫）。
- **用法**：`python -m Nitrogen.validate --anchors`（约 2.5 分钟）；
  `python -m Nitrogen.validate C5H5N`（指定分子式，如吡啶 685 个结构）。
- **状态**：独立库 / CLI，`Main.py` **未导入**该模块；N+O 组合（硝基 / 酰胺）未实现。
  详见 `Nitrogen/README_NITROGEN.md`。

### 2.5 可视化

- **3D 结构**：RDKit ETKDG 嵌入 + MMFF 力场优化，多进程并行计算坐标；不同环、双键(红)、三键(紫)用不同颜色；可旋转交互。
- **键线式（2D）**：RDKit `MolDraw2DSVG` + cairosvg 转 PNG，锯齿状碳链、双 / 三键平行线；甲烷有专门绘制。

### 2.6 质量保证

- **分子式一致性门禁** `filter_by_expected_formula`：全管线末端统一收口，剔除分子式与输入不符的泄漏结构。
- **高级结构筛选** `StructureConstraint`：必含基团（如苯环）、主链长度范围、环大小范围。
- **含氧官能团分类** `funcgroup.classify`：醇 / 酚 / 醚 / 过氧 / 醛 / 酮 / 羧酸 / 酯 / 环氧 / 含氧杂环 / 偕二醇，GUI 可多选「或 / 与」过滤。
- **含氮侧双门禁**：`Nitrogen/generator.py` 的 `add()` 收口处**先**价态硬校验
  （C ≤ 4 / N ≤ 3）**再**公式门禁——因公式门禁单独无法拦截"超价"结构（见 7.4）。

### 2.7 导出

一键导出 Gaussian `.gjf` 输入文件（对接量子化学计算）。

## 3. 软件架构（分层）

```
GUI 层 (Main.py, Tkinter)
   └─ 生成管理 (utils.GeneratorManager)：分子式解析 → 类型分发
        └─ 生成器层
             • AlkaneIsomerGenerator（烷烃）
             • RobustPolycyclicPolyeneGenerator（其余所有烃类）
             • HalogenSubstitutionGenerator（卤代）
             • UnifiedOxoGenerator / OxoSubstituentGenerator（含氧）
             • NitrogenGenerator（含氮，独立模块，尚未接入本层）
                  └─ 筛选层 (structure_filter)：约束 + 分子式门禁
                       └─ 工具层：图转换、WL 去重、公式校验、键线式渲染
                            └─ 可视化层：3D(matplotlib) / 2D(RDKit)
```

## 4. 关键算法

- **组合式分派**：按 `(环数, 双键数, 三键数)` 路由到 9 个子生成器。
- **烷烃骨架**：DFS + 整数划分枚举树 → 质心（centroid）去重消除对称重复。
- **成环**：BFS 逐轮加边；不饱和度 BFS 逐键升级（先三键后双键）。
- **去重**：Weisfeiler-Lehman 图哈希分桶 → 度签名预过滤 → VF2 精确同构检查；已修复长期存在的 WL 哈希碰撞误删。
- **含氧策略**：骨架 k 下探 + O 桥机制，配合进程池并行与「快速生成」开关加速。
- **含氮策略**：三种树机制 + 原子矩阵预言机。实测**机制 A（C→N 替换）单独即完备**
  （8/8 公式产物集合与预言机等值，含 C5H5N=685），但它**比预言机慢**（0.56~0.76×）——
  因在 `(nC+nN)` 个碳上做全不饱和度枚举、未做目标 H 剪枝，故生成任务宜直接用预言机。

## 7. 已知注意点

1. **README 技术栈过时**：README 写 PyQt5，实际代码为 Tkinter，复跑请以代码为准。
2. **图口径 vs 分子口径计数**：苯环等含环分子的凯库勒式变体在数学图口径下视为不同图、分开计数、不去重；这与 MAYGEN 的「一分子一 SMILES」分子口径不同，属刻意保留特性。
3. **依赖边界**：边界 / 完备性判断一律用内部预言机（O 系 `oxygen/boundary.py`；
   N 系 `Nitrogen/atomic_matrix_n.py`），**不依赖 MAYGEN**。N 系判据已完全内部化，
   MAYGEN 仅作可选脚本 `Nitrogen/maygen_compare.py`，不参与回归与 pass/fail。
4. **超价结构必须由价态门禁拦截——公式门禁单独不够**：氢数按
   `h = max(0, max_v − bond_load)` 计算，会把"超价"静默吸收为 h = 0，
   于是非法结构可能凑出目标 H 总数而通过公式门禁
   （N 系曾因此泄漏 N 载 4 键的结构）。→ 任何新增生成路径的收口处都须
   **先价态校验、再公式门禁**。
5. **含氮模块尚未接入 GUI**：N+O 组合（硝基 `-NO₂` / 酰胺 `-CONH₂`）与
   含 N 杂环约束路径（如"必含吡啶"）均未实现。
6. **文档目录**：全部项目文档已集中至 `Instruction Data/`；文档内对根目录资源
   （`MAYGEN/`、`Nitrogen/`、`tests/` 等）的引用为**相对项目根**的描述性文字。
